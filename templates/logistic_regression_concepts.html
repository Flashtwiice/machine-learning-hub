Logistic Regression — Concepts

The fundamentals of binary classification before the practical application.

What is Logistic Regression?

Logistic Regression is a supervised Machine Learning algorithm used to predict which of two possible categories an observation belongs to. Instead of predicting a continuous number, it estimates the probability that an observation belongs to a given class.

Why Is It a Classification Algorithm?

Even though it is built on a linear combination of the input variables, Logistic Regression passes that combination through a sigmoid function that squashes the result into a probability between 0 and 1, which is then converted into a discrete class label.

What Is Binary Classification?

Binary classification means the target variable can only take two possible values, for example 0 = No / 1 = Yes or 0 = Low Risk / 1 = High Risk.

Independent Variable

The input value used by the model to estimate the probability of belonging to each class.

Dependent (Target) Variable

The variable the model tries to classify. In binary classification it only has two possible outcomes.

Classes or Labels

The distinct categories the target variable can take. Each class is usually represented with a number (0 or 1) for the model to work with.

Probability of Belonging to a Class

For every prediction, the model first computes a probability (e.g. 82% chance of being "Diabetic") before deciding on a final class.

Classification Threshold

A cutoff value (commonly 0.5) used to convert a probability into a class: if the probability is above the threshold, the model predicts class 1; otherwise it predicts class 0.

Linear Regression vs. Logistic Regression

Linear Regression Logistic Regression
Output A continuous numeric value A probability (0 to 1) mapped to a class
Problem type Regression Classification
Function used Straight line: y = mx + b Sigmoid curve (S-shaped)

Core Machine Learning Concepts

The essential vocabulary you need to understand Machine Learning.

Dataset

A collection of data used to train, validate or test a Machine Learning model.

Features

Variables or characteristics used by a model to make predictions.

Label

The target value that a supervised model attempts to predict.

Model

A mathematical representation learned from data to perform predictions.

Training

The process of teaching a model by exposing it to training data.

Evaluation

Measuring how well a model performs on unseen data.

Accuracy

The proportion of correct predictions made by a classification model.

Overfitting

When a model learns the training data too closely and performs poorly on new data.

Generalization

The ability of a model to perform well on previously unseen data.

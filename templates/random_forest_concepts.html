Random Forest — Concepts

The assigned classification algorithm for this group.

What Is a Random Forest?

A Random Forest is an ensemble Machine Learning algorithm that builds many individual decision trees during training and combines their predictions (by majority vote for classification) to produce a single, more reliable result.

How Does It Work?

Each tree in the forest is trained on a random subset of the training data and considers a random subset of the features at each split (a technique called bagging). Because every tree sees the data slightly differently, their combined vote reduces the risk of overfitting to any single pattern in the data.

Types of Problems It Can Solve

Random Forests can be used for both classification (predicting a category, as in this activity) and regression (predicting a continuous number), and they naturally support multiple input variables.

Main Characteristics

  • Combines many decision trees (an ensemble)
  • Works well with several independent variables at once
  • Can rank variables by feature importance
  • Handles non-linear relationships between variables

Advantages

  • Generally more accurate and stable than a single decision tree
  • Less prone to overfitting
  • Handles non-linear patterns without manual feature engineering
  • Provides a built-in measure of which variables matter most

Limitations

  • Harder to interpret than a single decision tree ("black box")
  • Slower to train and predict with a large number of trees
  • Requires more memory to store many trees

A Real-World Example

An online store wants to predict whether a visitor will make a purchase based on their age, annual income, and how long they spend browsing the site. A Random Forest can combine all three variables to classify each visitor as "will purchase" or "will not purchase," which is exactly the problem implemented in this activity's Application page.

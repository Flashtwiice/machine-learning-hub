Linear Regression — Concepts

The fundamentals you need before looking at the practical application.

What is Linear Regression?

Linear Regression is a supervised Machine Learning algorithm that models the relationship between two quantitative variables by fitting a straight line to the observed data. It is one of the simplest and most widely used algorithms for making numeric predictions.

What Problems Can It Solve?

It solves regression problems: any task where the goal is to predict a continuous numeric value, such as prices, temperatures, consumption, sales, or scores, based on one input variable.

Independent Variable (X)

The independent variable is the input used by the model to make a prediction. It is also called the predictor or explanatory variable.

Dependent Variable (Y)

The dependent variable is the value the model tries to predict. Its value "depends on" the independent variable.

Relationship Between Variables

Simple Linear Regression assumes there is a linear relationship between X and Y: as X increases or decreases, Y tends to change proportionally.

Regression Line

The model learns the line y = m·x + b that best fits the training data, where m is the slope and b is the intercept. This line summarizes the trend in the data.

Prediction

Once trained, the model can take a new, unseen value of X and use the regression line to estimate the corresponding value of Y.

A Simple Example

If a company knows that, on average, monthly water use grows with the number of people living in a house, it can use Linear Regression to estimate the water consumption of a new household just by knowing how many people live there.
